# v0.5.0: Codex Skills for OCI Enterprise AI Deployment

Release date: 2026-10-02.

## From a prompt to an agent running on OCI

This release gives Codex five skills that take an AI agent from a
plain-language request to a verified release on **OCI Enterprise AI Hosted
Applications**. The developer describes what they want; Codex creates, builds,
publishes, deploys, and verifies the agent, and asks for approval before every
change in OCI.

```text
Create a new OCI agent: POST /analyze receives a text and returns the number of words.
Release version 0.1.0 of this agent on OCI Hosted Applications.
```

## The skills

| Skill | What it does |
| --- | --- |
| `oci-agent-new` | Creates an agent repository from a prompt or a specification file: `agent.yaml`, `Dockerfile`, a FastAPI agent, functional checks. Checks the tenancy settings and never overwrites existing files. |
| `oci-agent-build` | Builds a `linux/amd64` image and verifies it locally on a read-only filesystem, with health, readiness, and functional checks. |
| `oci-agent-push` | Publishes the verified image to OCIR, creating the repository when it is missing, each step after explicit approval. |
| `oci-agent-deploy` | Reads the state in OCI, shows a plan, and after approval creates the release, adds a new version, or rolls back, in the same Hosted Application. |
| `oci-agent-verify-deployment` | Confirms the active release in OCI and calls `/health`, `/ready`, and the agent's functional checks. |

## Highlights

* **Plan first, approve every change.** Push and deploy show what will happen
  and run only after an explicit approval; a request to deploy never
  authorizes a push on its own.
* **New versions and rollback without a new endpoint.** Every release reuses
  the same Hosted Application; rolling back means deploying the previous tag.
* **Reliable deployments.** The deploy waits for OCI with visible progress,
  reports the OCI error when a creation fails, resumes an interrupted wait,
  and, on request, replaces a failed deployment.
* **One manifest per agent.** `agent.yaml` holds build, publish, deploy,
  runtime variables, and functional checks; the version tag is always given
  explicitly.
* **Two access modes.** `public-noauth`, or `public-idcs` for endpoints that
  require a JWT token from an OCI IAM identity domain.
* **Runtime variables.** Literal values, values read from the operator's
  shell, or OCI Vault secrets.
* **Bash and PowerShell 7.4+.** Every lifecycle script has twins with the same
  options and exit codes.
* **Documentation.** A Quickstart, a step-by-step guide, the agent manifest
  reference, and the IAM policies for operators and Hosted Applications.

## Verified on OCI

All live tests ran in **eu-frankfurt-1**, from macOS with the Bash scripts.

| Date | Agent | Result |
| --- | --- | --- |
| 2026-09-22 | `hello-world` 0.1.0 | First release: Hosted Application and deployment `ACTIVE` from the published OCIR image. |
| 2026-09-23 | `hello-world` 0.2.0 | Remote verification: OCI state, release tag, `/health`, `/ready`. |
| 2026-09-30 | `text-stats` | Switching the active version took about 10 seconds, with no observed interruption and the same endpoint. |
| 2026-10-01 | `word-count` 0.1.0 | Agent created from a prompt with `oci-agent-new`, then built, pushed, deployed, and verified. |
| 2026-10-01 | `order_processing` 0.1.0 | LangGraph agent that extracts product and quantity with an LLM through the OCI OpenAI-compatible Responses API, created with `oci-agent-new`; released and verified, functional calls in Italian and English. |
| 2026-10-02 | `order_processing` 0.1.1 | First release with the new reliable wait: application `ACTIVE` in 62 s, deployment `ACTIVE` in 92 s, no manual step; remote functional verification passed. |

Design decisions, acceptance criteria, and verification details are in the
[specifications](../../specs/).

## Tested with

* OCI CLI 3.94.0 and OCI Python SDK 2.187.0.
* Python 3.11, in the Conda environment `codex-4-oci-enterprise-ai-deployment`.
* Docker with Buildx on macOS (Apple Silicon, `linux/amd64` builds).
